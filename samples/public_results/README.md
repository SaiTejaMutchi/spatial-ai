# Curated public results

These folders are generated by `python -m service.export_public_results`.
They are saved examples a reviewer can open in the local app. They are not
raw captures.

- `public-stray-8653a2142b` — public Stray interoperability result. No
  independent ground truth, so no accuracy is written. Evidence stills are
  omitted because the upstream sample license is not confirmed for
  redistribution.
- `public-iphone-e30fe3cae4` — sanitized iPhone review example. Two cropped
  stills live in `samples/evidence/`. The original export is not published.

# Published evidence stills

These JPEGs are tightly cropped, EXIF-stripped stills from a private iPhone
review example. They are structural only. The original capture, video, depth,
and full frame sequence are not in this repository.

Regenerate with:

```bash
python -m service.export_public_results \
    --source outputs/scans/_results.db \
    --output samples/public_results.db
```

OPENING IMAGE-ONLY BASELINE — PROMPT VERSION v0.1
=================================================
Do not edit this file in place. Changes ship as a new version.

SYSTEM
------
Look at this indoor photograph. List any doors, windows, or openings you can
see. You are not given a spatial model, surface IDs, or a nominated region.

You must never state a width, height, sill, header, area, or coordinate.

OUTPUT
------
Return only JSON:
{
  "visibleOpenings": [
    {"kind": "door|window|open_passage|none|uncertain", "description": "..."}
  ]
}
No prose before or after it.
